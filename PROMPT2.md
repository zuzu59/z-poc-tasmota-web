# Objectif

Écris un petit script en Beryl pour Tasmota qui sert une page web accessible à l’adresse `http://<ip_tasmota>/web`.

# Contenu de la page

La page doit afficher le texte **Hello zuzu**, en grand, centré horizontalement et verticalement. La mise en page doit rester lisible sur les écrans mobiles comme sur les ordinateurs.

# Résultat attendu

- Fournis le script complet, prêt à être utilisé avec Tasmota.
- Indique brièvement comment l’installer et le lancer sur Tasmota, ainsi que les prérequis éventuels.
- Respecte les contraintes de Beryl et des capacités web de Tasmota ; signale clairement toute hypothèse nécessaire.
- N’ajoute pas de fonctionnalités sans rapport avec cette page.

# Critères de réussite

En ouvrant `http://<ip_tasmota>/web` dans un navigateur, on obtient la page demandée et le texte **Hello zuzu** apparaît en grand au centre.
